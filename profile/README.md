# Mobifreaks

In 2010 phones were getting real browsers, but most websites weren't ready for them. [M Munawar Ahmed](https://munawarahmed.com) started Mobifreaks to share free mobile website templates. For a while it ranked #1 on Google for "Free Mobile Website Templates", and people around the world built their sites on them.

All 22 templates are open source under the MIT license, with live demos. See them all on a phone frame at **[munawarahmed.com/mobifreaks](https://munawarahmed.com/mobifreaks)**.
